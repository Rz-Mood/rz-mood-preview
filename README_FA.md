# RZ Station — Free To Use Edition (preview v20)

## منبع موسیقی
- جست‌وجوی اصلی از API عمومی Free To Use v3 انجام می‌شود.
- آهنگ‌های Premium فیلتر می‌شوند.
- عنوان آهنگ، نام هنرمند و لینک Free To Use برای انتساب نمایش داده می‌شود.
- اگر API اصلی در دسترس نباشد، جست‌وجو به Internet Archive برمی‌گردد.
- رادیو به‌صورت پیش‌فرض Free To Use را امتحان می‌کند؛ در صورت نبود نتیجه، Internet Archive پشتیبان است. Jamendo نیز با Client ID اختیاری قابل انتخاب است.

## نکته مجوز
این نسخه برای استفاده شخصی و غیرتجاری آماده شده است. شرایط رسمی Free To Use برای جاسازی موسیقی در وب‌سایت/اپلیکیشن ممکن است به مجوز جداگانه نیاز داشته باشد؛ پیش از انتشار عمومی یا تجاری باید مجوز مربوطه بررسی شود. فایل‌های موسیقی را جداگانه بازتوزیع نکنید.

## حفظ اطلاعات
این نسخه داده‌های محلی مرورگر را پاک نمی‌کند. تاریخچه، علاقه‌مندی‌ها، تنظیمات و کلیدهای ذخیره‌شده دست‌نخورده می‌مانند.

## انتشار
فایل‌های پروژه را در شاخه آزمایشی GitHub Pages جایگزین کنید. سپس سایت را با Ctrl+F5 تازه‌سازی کنید. Service Worker با cache جدید `rz-station-v20` به‌روزرسانی می‌شود.


## جداسازی داده‌های Preview
در مسیر `rz-mood-preview`، داده‌های localStorage با پیشوند `rz-preview:` ذخیره می‌شوند تا تاریخچه و تنظیمات نسخه اصلی در همان دامنه GitHub Pages دست‌نخورده بمانند.
